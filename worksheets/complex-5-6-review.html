1하
\(2i\)의 실수부분을 \(a\), 허수부분을 \(b\)라고 할 때, \(a+b\)의 값을 구하시오. (단, \(i=\sqrt{-1}\))
✏️ 필기로 풀이 쓰기
내 답 입력
\(2i = 0 + 2i\) 이므로 실수부분 \(a=0\), 허수부분 \(b=2\)
\(\therefore\ a+b = 0+2 = 2\)
✓ 학생 답 2

2하
등식 \((x-2)+(y+1)i=1+2i\)를 만족하는 실수 \(x, y\)에 대하여 \(x+y\)의 값을 구하시오. (단, \(i=\sqrt{-1}\))
✏️ 필기로 풀이 쓰기
내 답 입력
실수부분과 허수부분을 각각 비교하면 \(x-2=1,\ y+1=2\)
\(x=3,\quad y=1\)
\(\therefore\ x+y = 3+1 = 4\)
✓ 학생 답 4
정답 4
3하
\((4+7i)+(2-3i)\)를 계산하면? (단, \(i=\sqrt{-1}\))
\((4+7i)+(2-3i) = (4+2)+(7-3)i\)
\(= 6+4i\)
✓ 학생 답 ⑤ 6+4i

4중
\(\dfrac{1}{i^{201}}+\dfrac{1}{i^{203}}\)의 값은? (단, \(i=\sqrt{-1}\))
\(i^{201} = i^{4\cdot50+1} = i\),   \(i^{203} = i^{4\cdot50+3} = -i\)
\(\dfrac{1}{i} = -i, \quad \dfrac{1}{-i} = i\)
\(\dfrac{1}{i^{201}}+\dfrac{1}{i^{203}} = -i + i = 0\)
✓ 학생 답 ② 0

5중상
다음 보기 중에서 허수가 아닌 것을 모두 고른 것은? (단, \(i=\sqrt{-1}\))
ㄱ. \(3+2i\) ㄴ. \(3\pi\) ㄷ. \(1-i\) ㄹ. \(\sqrt{2}\) ㅁ. \(4i\)
허수가 아닌 것 = 실수인 것
ㄴ. \(3\pi\)와 ㄹ. \(\sqrt2\)는 허수단위 \(i\)가 없는 실수
ㄱ, ㄷ, ㅁ은 모두 \(i\)를 포함한 허수
✓ 학생 답 ③ ㄴ,ㄹ

6하
\(\alpha=1+i,\ \beta=1-i\)일 때, \((\alpha-\beta)(\bar\alpha-\bar\beta)\)의 값을 구하시오.
(단, \(\bar\alpha, \bar\beta\)는 \(\alpha, \beta\)의 켤레복소수이고 \(i=\sqrt{-1}\))
✏️ 필기로 풀이 쓰기
내 답 입력
켤레복소수: \(\bar\alpha=1-i,\ \bar\beta=1+i\)
\(\alpha-\beta=(1+i)-(1-i)=2i\)
\(\bar\alpha-\bar\beta=(1-i)-(1+i)=-2i\)
\((\alpha-\beta)(\bar\alpha-\bar\beta)=(2i)(-2i)=-4i^2=4\)
✓ 학생 답 4
정답 4
7상
복소수 \(a+bi\)에 대하여 \(a, b\)가 실수일 때, 허수부분의 부호를 바꾼 복소수 \(a-bi\)를 복소수 \(a+bi\)의 ___라 하고, ___로 나타낸다. 다음 빈칸에 들어갈 말을 순서대로 나열한 것은? (단, \(i=\sqrt{-1}\))
허수부분의 부호를 바꾼 복소수를 켤레복소수라 하고, \(\overline{a+bi}\)로 나타낸다 (bar가 전체 식 위에).
✓ 학생 답 ④
정답 ④
8중
\(\dfrac{1-i}{1+i}+\dfrac{1+i}{1-i}\)를 계산하면? (단, \(i=\sqrt{-1}\))
\(\dfrac{1-i}{1+i} = \dfrac{(1-i)^2}{(1+i)(1-i)} = \dfrac{-2i}{2} = -i\)
\(\dfrac{1+i}{1-i} = i\) (켤레 관계이므로 부호만 반대)
\(-i + i = 0\)
✓ 학생 답 ③ 0

\(= 2+7i-6 = -4+7i\)
✓ 학생 답 ② -4+7i

15중상
복소수 \(z=2+3i\)의 켤레복소수를 \(\bar z\)라고 할 때, 다음 중 옳지 않은 것은? (단, \(i=\sqrt{-1}\))
\(\bar z=2-3i\), \(z+\bar z=4\), \(z-\bar z=6i\), \(z\bar z=4+9=13\) — 모두 성립
\(\dfrac{\bar z}{z}=\dfrac{2-3i}{2+3i}=\dfrac{(2-3i)^2}{13}=\dfrac{-5-12i}{13}\ne 13i\)
따라서 옳지 않은 것은 ⑤
✓ 학생 답 ⑤

23최상
다음 수들에 대한 |보기|의 설명 중 옳은 것을 모두 고른 것은?
\(-2,\; 2-3i,\; -\sqrt5\,i,\; -2i+\sqrt5,\; \dfrac13-\sqrt2\,i,\; \dfrac{\pi}{3},\; 0,\; -i^2,\; i^{-1}\)
ㄱ. 복소수는 모두 3개다. ㄴ. 순허수는 오직 1개다. ㄷ. 허수는 모두 4개다. ㄹ. 실수는 모두 4개다.
⚠️ 학생 답 ② (ㄴ,ㄷ)는 오류가 있어요. 순허수(실수부분이 0인 허수)는 \(-\sqrt5 i\)와 \(i^{-1}=-i\) 이렇게 2개이므로 "순허수는 오직 1개다"(ㄴ)는 틀린 설명이에요.
다만 손글씨로 적힌 수 목록이 일부 흐릿해서 정확한 정답(③ 또는 ⑤로 추정)은 실제 정답지와 대조해서 다시 확인하는 걸 추천해요.
✕ 학생 답 ② ㄴ,ㄷ
